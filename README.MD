
# Introduction

This repo is bascially where I save all the artifacts from my trying to learn physics.

# Layout

The root is where you find this README.md. Under scripts you will find all the relavent scripts for the overall repo, under subjects is where all the artifacts are located.

# Building

To build all the artifacts in this repo you just need to run,

```
build.(ps1|py)
```

which will then build all artifacts in the repo. If you only want to build specific ones you can add a filter like this,


```
build.(ps1|py) physics
```

this will then build whatever path matches the filter.
